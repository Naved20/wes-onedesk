HOW IT WORKS:
-------------

Example: DPS Shift
- Start time: 08:10
- End time: 15:10
- Last check-in: 0.5 hrs before end = 14:40

Timeline:
08:10 -------- 14:40 -------- 15:10
      ^                ^         ^
   Shift Start    Last Check  Shift End
                   Deadline

- Agar employee 14:40 se pehle check-in kare = Present/Late
- Agar employee 14:40 ke baad check-in kare = Absent
- Agar 14:40 tak check-in nahi kiya = Auto-mark Absent

   ```sql
   SELECT 
     'Absent' as metric,
     COUNT(*) as count
   FROM attendance
   WHERE date = CURRENT_DATE

   ```

AUTOMATIC SCHEDULING (OPTIONAL):
---------------------------------

To automatically create absent records every hour:

1. Enable pg_cron in Supabase dashboard
2. Run this query:
   ```sql
   SELECT cron.schedule(
     'auto-create-absent-records',
     '0 * * * *',
     $$SELECT create_absent_records_for_date(CURRENT_DATE)$$
   );
   ```

This will check every hour and create absent records for employees
whose shift deadline has passed.

IMPORTANT NOTES:
----------------

1. Absent records only created AFTER shift's last check-in time
2. Holidays and Sundays are skipped
3. Future dates are skipped
4. Only active employees are considered
5. Employees without shift assignment are marked absent for past dates only
