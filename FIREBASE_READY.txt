TECHNICAL DETAILS:
═════════════════════════════════════════════════════════════════════════════════

Architecture:
App Event → Notification Service → DB + FCM Function → Firebase → Mobile

Flow:
1. User action (Approve, Generate, etc)
2. Notification saved to database
3. Cloud Function invoked
4. Function gets FCM token from DB
5. Sends to Firebase Cloud Messaging
6. Firebase routes to device
7. Device shows notification
8. User taps → Opens app

Security:
✓ FCM tokens stored in database
✓ RLS policies protect tokens
✓ Service account for backend
✓ No credentials in frontend code
✓ Tokens auto-refresh

Performance:
✓ Notifications sent async (fast)
✓ No blocking operations
✓ Error handling graceful
✓ Fallback support
