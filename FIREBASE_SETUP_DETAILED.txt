STEP 10: DEPLOY CLOUD FUNCTION (10-15 minutes)
═════════════════════════════════════════════════════════════════════════════════

10.1 Open terminal in your project:
    Command line / PowerShell / Terminal
    
    Navigate to project root:
    cd c:\MD_naved\new-onedesk\wes-onedesk

10.2 Install Supabase CLI (if not installed):
    Command:
    npm install -g supabase
    
    Or if you use bun:
    bun add -g supabase

10.3 Login to Supabase:
    Command:
    supabase login
    
    This opens browser → Sign in with your Supabase account
    
    Copy the access token shown and paste in terminal
    Press Enter

10.4 Link project to Supabase:
    Command:
    supabase link
    
    It asks: "Enter your project ref or project URL"
    
    From Supabase dashboard → Settings → General → Project ref
    Copy the ref (looks like: abc123def456)
    
    Paste it and press Enter

10.5 Deploy the Cloud Function:
    Command:
    supabase functions deploy send-fcm-notification
    
    This uploads the function to Supabase Edge Functions
    
    You should see:
    ✓ Function deployed successfully
    ✓ Endpoint: https://xxx-xxx-xxx.functions.supabase.co/send-fcm-notification

10.6 Get the function URL:
    From the output, copy the endpoint URL
    
    Example: https://abc123def456.functions.supabase.co/send-fcm-notification
    
    👉 SAVE THIS URL! (You might need it for testing)

STEP 13: TROUBLESHOOTING (If something doesn't work)
═════════════════════════════════════════════════════════════════════════════════

ISSUE 1: "No notification on mobile"

Solution:
□ Check .env file - all credentials correct?
□ Restart app (npm run dev)
□ Check phone notification settings (Allow notifications?)
□ Check browser console for errors (F12)
□ Check if FCM token saved (Supabase → Table Editor → user_fcm_tokens)

ISSUE 2: "Credentials error"

Solution:
□ Double-check .env values (no extra spaces)
□ Re-generate credentials from Firebase
□ Make sure quotes are correct: "value"
□ Restart npm run dev

ISSUE 3: "Cloud Function not deploying"

Solution:
□ Check Supabase login: supabase login
□ Check project link: supabase link
□ Check firebaseConfig.ts file exists
□ Try again: supabase functions deploy send-fcm-notification

ISSUE 4: "App crashes when notification arrives"

Solution:
□ Check browser console errors
□ Check notification data format
□ Verify deep linking setup
□ Add error boundary in app
